# Shared animated liquid rendering (Minecraft 26.2)
- **Cause:** the earlier fluid render path bound the raw vertical spritesheet PNG with UV range 0..1/32 and used entityTranslucent. Only frame zero ever rendered; it blended a dark oil/washed-out water over the vessel floor.
- **Fix:** look up each still-fluid sprite via `Minecraft.getInstance().getAtlasManager().getAtlasOrThrow(AtlasIds.BLOCKS)` on render. Feed sprite atlas UVs to `RenderTypes.entityCutout(TextureAtlas.LOCATION_BLOCKS)`. This reuses the *same atlas animation* as flowing fluid blocks and uses solid compositing like vanilla cauldron model faces.
- **Water color:** `BlockTintSources.water()` applied in both Barrel and generic custom cauldron at the world position; no hardcoded pale-blue overlay.
- **Oil:** original Rustic `block/fluids/olive_oil_still` sprite (including its mcmeta animation), untinted, as it is in the world.
- **Milk/whey:** static existing art is stitched into the block atlas via an additive `assets/minecraft/atlases/blocks.json`. Any future fluid uses `registerSurface(fluidId, spriteId, color)` and the same engine; animated mcmeta advances in the normal atlas.
- **Height:** vanilla full cauldron surface is at 15/16 block (model `template_cauldron_full`); the old 11.95/16 was low. Four 250mB steps now scale from 9/16 (250mB) to 15/16 (1000mB), matching vanilla water/lava full-height. Barrel heights remain 2/16..15/16, matching Rustic 1.12.2.
- **Creative middle click:** `getCloneItemStack` returns `minecraft:cauldron` from both the generic filled cauldron and legacy olive-oil cauldron.
- **Native behavior:** no global overwrite of vanilla cauldrons; regular vanilla empty, water, and lava cauldrons still work. A custom fluid temporarily uses one technical filled block with the native metal model, as in other modded-cauldron implementations. This technical block is necessary to store arbitrary fluid type/volume without overwriting vanilla block classes.
- **Manual verification:** check water in vanilla cauldron versus barrel in same biome/light, animated oil in all 3 positions, surface 15/16 and creative middle click; recheck existing saves and mixed liquids. The build alone cannot prove the visual result.
