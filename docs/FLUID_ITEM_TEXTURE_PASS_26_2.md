# Liquid containers — vanilla-aligned sprites

- Bottles of sheep milk, whey, olive oil, apple juice, rennet and apple cider vinegar use the **identical vanilla potion glass model** and a unique constant tint, never custom antiquated bottle silhouettes.
- Existing IDs remain unchanged; no world/inventory migration is needed.
- Whey bucket and whey bottle are both pale warm cream (#EBDDB1); the vanilla iron bucket rim is not tinted.
- Recolored bucket PNGs have strictly binary alpha 0 or 255, like existing project policy.
- Rennet and apple cider vinegar now each have a 1000mB bucket with dedicated items, bucket and bottle recipes.
- Warning: the new bucket items are non-placeable crafting/processing liquids (like whey), not flowing world fluids.
