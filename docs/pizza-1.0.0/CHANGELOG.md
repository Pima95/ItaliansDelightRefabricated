# Italian's Delight Refabricated — Changelog 1.0.0

**Pizza Update · pubblicata il 23 ottobre 2026** · [Release GitHub](https://github.com/Pima95/ItaliansDelightRefabricated/releases/tag/v1.0.0)

## Novità

- Preparazione della pizza nel mondo: impasto di Farmer's Delight, stesura a mano o con mattarello, divisione in quattro quarti e condimenti indipendenti con rimozione reversibile.
- **18 gusti riconosciuti** e Pizza Mista, con ingredienti, aspetto e nome preservati per ogni spicchio.
- **Pizza Oven** con combustibile, interfaccia e automazione, cottura alternativa in fornace o affumicatore; **Pizza Peel** riutilizzabile.
- Quattro spicchi servibili o ottenibili con il Cutting Board; nutrizione dipendente dai condimenti e pile fino a 16 spicchi identici.
- Ricette e istruzioni in **JEI**, campioni nell'inventario creativo, correzioni di salvataggi, contenitori, drop e compatibilità con i prodotti caseari.
- Coltivazione del cardo ampliata, generazione selvatica di cardo e basilico rivista, aggiornamenti agli uncini di stagionatura.

## Requisiti della versione rilasciata

Minecraft **26.2** · Fabric Loader **0.20.1+** · Fabric API **0.161.0+26.2** · Farmer's Delight Refabricated **3.6.29** · Java **25**. JEI supportato.

## Note di compatibilità

Eseguire un backup dei mondi prima dell'aggiornamento. Processi non terminati nella Cheese Vat avviati con vecchie build di sviluppo possono perdere il progresso parziale a causa di variazioni degli ID ricetta. Alla pubblicazione non era disponibile un collaudo multiplayer completo.

La versione pubblicata 1.0.0 conserva i termini di licenza **MIT** già applicabili.
